# The Wintering Well — production website

Live site: https://akrammk5.github.io/The-Wintering-Well-A-Cozy-Guide/

This repository contains the static landing page for **The Wintering Well: A Cozy Guide to Finding Joy in the Quiet Season**.

## Production files

- `index.html` — live landing page
- `privacy.html` — privacy notice
- `contact.html` — help/contact page
- `robots.txt` — crawler directives
- `sitemap.xml` — search-engine sitemap
- `llms.txt` — concise machine-readable book/site summary
- `favicon.svg` — site icon

## Deployment

The site is deployed with GitHub Pages from the `main` branch.

## SEO and trust rules

- Keep the canonical URL as `https://akrammk5.github.io/The-Wintering-Well-A-Cozy-Guide/`.
- Keep structured data aligned with visible page content.
- Do not publish fabricated reviews, sales counts, stock scarcity, or countdown timers.
- Verify current formats and prices on Amazon instead of hardcoding them.
- Update `sitemap.xml` when public pages are added or removed.
- Update `privacy.html` before enabling analytics, advertising, or email collection.

## Legacy files

`README-IMPLEMENTATION.md`, `script-enhanced.js`, `styles-enhanced.css`, and the Python generation scripts are older development artifacts. They are not loaded by the current production page.
